# 📖 Overview

Memory Capsule AI is an intelligent document understanding platform designed to help users transform unstructured text into organized knowledge.

The system combines multiple Natural Language Processing (NLP) techniques and AI-powered utilities into one application, allowing users to summarize documents, compare articles, generate quizzes, discover relationships between concepts, search semantically, and convert text into speech.

It serves as a personal AI knowledge assistant for students, researchers, professionals, and lifelong learners.

---

# 🎯 Objectives

- Extract meaningful information from documents
- Summarize lengthy articles
- Generate quizzes automatically
- Perform semantic search
- Compare multiple documents
- Build concept relationships
- Convert knowledge into audio
- Improve learning efficiency

## 📝 AI Summarization

Automatically generates concise summaries while preserving important information.

---

## 🔍 Semantic Search

Instead of keyword matching, the application retrieves information based on semantic meaning, improving search accuracy.

---

## 🧠 Concept Mapping

Automatically identifies important concepts and their relationships to help users visualize knowledge.

---

## 📚 Quiz Generator

Generate revision questions from documents, making learning interactive and effective.

---

## ⚖️ Article Comparison

Compare two articles and identify:

- Similarities
- Differences
- Shared topics
- Key insights

---

## 🔊 Text-to-Speech

Convert summarized content into speech, allowing users to listen instead of reading.

---

## 🌐 Interactive Web Interface

A lightweight interface built for easy interaction with AI-powered document analysis tools.


